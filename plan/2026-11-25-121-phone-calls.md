# Plan: place phone calls from Nixi, with contact names on the handset

This plan stands on its own. It carries every approved intent and spec
decision, so a coder never needs to open the spec.

## Approved decisions

- **D1. Contacts** come from Bluetooth PBAP through `obexd`, the session
  bus `org.bluez.obex`. The owner turns on Contact sharing per host. A
  Flux `contacts.search` is a later fallback only.
- **D2. The phonebook cache:**
  - it is per Bluetooth address, in memory, and lasts 10 minutes;
  - failures are cached too, with a 5-minute backoff;
  - it is dropped, and its generation bumped, on gateway loss, Phone off
    and desktop lock;
  - a worker from an older generation discards its result.
- **D3. Which phone dials:**
  - one HFP gateway: it is used;
  - several: a phone pick card, listed by BlueZ alias from the system
    bus, with the last 4 characters of the address added when two aliases
    are the same;
  - none: "not connected over Bluetooth".

  This replaces the intent's "Flux-paired" rule, as the approved spec
  says. A caller's name comes only from the phonebook of the gateway
  carrying that call.
- **D4. Typed numbers** are allowed, through the same confirm card.
- **D5. Privacy:**
  - phonebook names are only shown, never spoken;
  - `on_missed` and anything spoken get only `phone_who`, the name the
    phone sent;
  - replies never repeat the target or a full number;
  - nothing logs names or numbers;
  - the vCard file lives only in a `0700` directory
    `$XDG_RUNTIME_DIR/nixi-pbap-<random>`. It is deleted in `finally`,
    and stale ones are deleted at startup.
- **D6. Safety:**
  - only a trusted pointer click on the confirm card dials, never voice,
    Enter or Space;
  - `PHONE_CALL` tokens are bound to the request `id`, to `PHONE_GEN`, and
    to a 60 s expiry. A new request replaces the old one;
  - `DIAL_PENDING` blocks a second dial until HFP shows the call, or for
    30 s. An `unknown` dial result keeps it;
  - there is no dial while a call is showing or in progress.
- **D7. Allowed numbers** (`allowed_number`):
  - normalise: strip `tel:`, Unicode spaces, dashes (`-`, `‐`–`―`),
    dots and brackets;
  - allowed: `+?[0-9]{6,15}`;
  - refused as `not_allowed`: anything containing `* # , ; p w`
    (case-insensitive);
  - refused as `short`: 1 to 5 digits;
  - the rule applies to contact numbers too.
- **D8. Lock order:**
  - `Call.lock` is taken before `PHONE_LOCK`, never the other way round;
  - `Pbap` never holds its own lock while it calls a callback;
  - `Call.visible()`, `phone_on_screen()` and `Hfp.any_call()` are never
    called while `PHONE_LOCK` is held.

1. **`app/pbap.py` (new) and `tests/test_pbap.py` (new).** Codex.
   - **The `Pbap(conn=None, gio=None, glib=None)` class.** Its
     connection is injectable, as `Hfp` does at `hfp.py:21`. Signals are
     dispatched on its own GLib main context thread, as `Hfp._run` does
     (`hfp.py:79-90`). Its methods:
     - `start()`: delete stale `$XDG_RUNTIME_DIR/nixi-pbap-*` directories
       and start the context;
     - `state(address)`: one of `ready`, `loading`, `sharing`,
       `unreachable`, `failed` or `cold`. An entry older than 10 minutes,
       or a failure older than 5 minutes, reads `cold`;
     - `ensure(address, cb)`: if `cold`, start one worker for that
       address. In every case, add `cb` to that address's waiter list,
       so callers join a load already in progress. When the load ends,
       the waiters are taken out under the lock, the lock is released,
       and each is called with the final `state(address)`. They are
       called for every end state, not only `ready`;
     - `name_for(address, number)`: read the cache only and never block.
       It returns `(name, label)` for exactly one exact-key match. With
       no exact entry, it returns the one contact number whose last 8
       digits match. Two or more candidates, or no hit, give `None`;
     - `search(address, query)`: case- and accent-insensitive (NFKD,
       then strip combining marks). Exact name first, then word-prefix,
       then substring. At most 8 people, each `{name, numbers:
       [(label, number)]}`, with dialable numbers only;
     - `drop(address=None)`: bump the generation for that address, or
       for all, and clear its entry and waiters.
   - **Loading** (`_load(address, gen)`, on a worker thread):
     1. `Client1.CreateSession(address, {"Target": GLib.Variant("s","pbap")})`
        gives the session path.
     2. `PhonebookAccess1.Select("int", "pb")`.
     3. Subscribe to `org.freedesktop.DBus.Properties.PropertiesChanged`
        on the obex bus **before** `PullAll`.
     4. `PullAll(<abs path>/pb.vcf, {"Format": "vcard30", "Fields": ["FN","N","TEL"]})`
        gives `(transfer_path, props)`. Keep only the signals whose path
        equals `transfer_path`.
     5. If `props["Status"]` is already `complete` or `error`, use it.
        Otherwise wait for a terminal `Status`, for up to 20 s. On
        timeout, call `Transfer1.Cancel()`.
     6. Parse only after `complete`.
     7. In a `finally`: unsubscribe, delete the file and the directory,
        and call `Client1.RemoveSession(session)`.
     8. Write the cache entry only if `gen` is still current.
   - **Errors:**
     - a D-Bus error name containing `NotAuthorized` or `Forbidden` from
       `CreateSession`, or any error from `Select` or `PullAll`, gives
       `sharing`;
     - any other `CreateSession` error gives `unreachable`;
     - a transfer `error` or a timeout gives `failed`.
   - **Parsing:**
     - the name is `FN`, falling back to `N` joined;
     - for `TEL`, the `TYPE` maps `CELL`→mobile, `HOME`→home,
       `WORK`→work, else other;
     - a number keeps its display form and gets a key: digits only, plus
       a leading `+` marker if present;
     - numbers that fail D7 are kept, but marked as not dialable.
   - **`allowed_number(raw)`** is a module-level function implementing D7.
     It returns `("ok", normalised)`, `("short", None)` or
     `("not_allowed", None)`.
   - **Logging:** errors by type only. Never log names or numbers.
   - **Tests** (synthetic vCards and a fake bus only):
     - parsing: `FN`/`N` fallback, labels, `tel:`, Unicode dashes,
       non-dialable numbers;
     - search order and accents, and the 8-match limit;
     - `name_for`: an exact key, a unique suffix, a suffix collision
       giving `None`, and duplicate contacts;
     - the transfer: already `complete` from `PullAll`, completion after
       subscribing, `error`, and a timeout that calls `Cancel`. In each
       case the file and the directory are gone;
     - error mapping (`sharing`, `unreachable`, `failed`), and the
       5-minute backoff;
     - a generation bump during a load discards it;
     - the 10-minute expiry, one load per address, and a second waiter
       joining a load in progress;
     - waiters are called outside the lock, for every end state;
     - `allowed_number`: `+4791234567` is ok, `112` and `12345` are
       short, `*#06#`, `123,45` and `0123p4` are not allowed, and
       `tel:+47 912-34 567` normalises;
     - startup cleanup.
   - **Check:** `nix develop -c python3 -B -m unittest discover -s tests -p 'test_pbap.py'`
   - **Traps:** never touch the real `obexd`, Bluetooth or contacts. The
     target path must be absolute. Waiters are called after the lock is
     released (D8).
